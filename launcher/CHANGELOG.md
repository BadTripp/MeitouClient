# Launcher changelog

Released with tags `launcher-v<version>` by `.github/workflows/launcher-release.yml`; each release needs its `## v<version>` section.

## v0.1.0

- First prototype: installs game releases from GitHub (stable or with pre-releases), edits the mod list like Kenshi's launcher
  (order, enable, `mods.cfg`), mod presets, RE_Kenshi plugin mods marked, starts the game with the chosen Kenshi folder.
